Letakkan ikon PWA di sini:
- icon-192.png (192x192)
- icon-512.png (512x512)

Saat scaffolding, ikon placeholder dapat di-generate dari logo MENALA via
tools online (favicon.io / realfavicongenerator.net) atau skrip ImageMagick:

  magick convert logo.png -resize 192x192 icon-192.png
  magick convert logo.png -resize 512x512 icon-512.png
