Input Transaksi Baru

Buka Google Form via PWA rifim-finance-pwa untuk catat pemasukan / pengeluaran / kasbon dari HP.
📝 Google Form (via rifim-finance-pwa) 📊 Auto-append ke sheet LIA
Flow: Klik tombol di bawah → buka rifim-finance-pwa.vercel.app (halaman boarding-pass) → tap "Buka Form" → Google Form input → response auto-tersimpan di sheet LIA (474 baris per snapshot) → cron GAS pindah ke sheet FINANCE + sheet cabang yang sesuai.
Kolom form (dari sheet LIA): Timestamp, Email, Pemasukan, Pengeluaran, Cabang, Keterangan, Bukti Foto, Nama Staff (Kasbon).
Alternatif inline (later): port form ke modul CRM/Finance sebagai modal internal supaya user tidak perlu keluar portal.
