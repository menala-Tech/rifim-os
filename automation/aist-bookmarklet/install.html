Fill AIST Saldo — Bookmarklet Install (Semi V2)

Bookmarklet field-filler untuk form Balance replenishment di AIST. Payload dipilih dari RIFIM Finance → Isi Saldo (RAOS), ditransfer lewat clipboard.

1. Drag tombol ini ke bookmark bar

🔴 Fill AIST Saldo

Tarik ke Bookmarks Bar Chrome/Edge/Brave. Kalau bar tidak muncul: Ctrl+Shift+B.

2. Alur operator (semi-auto, non-Lunas)

1. Buka RIFIM OS → Finance → Isi Saldo (RAOS).
2. Pilih request yang mau diproses (status pending/approved). Verifikasi Cabang / Staff / Driver / Login / Nominal.
3. Klik 🪄 Fill AIST. Popup konfirmasi muncul, payload sudah tersalin ke clipboard.
4. Pindah ke tab AIST → Document → Add → Balance replenishment. Pilih Subdivision + Currency manual seperti biasa.
5. Setelah form terbuka, klik bookmark Fill AIST Saldo. Bookmarklet membaca clipboard, memvalidasi payload + TTL, meminta konfirmasi, lalu mengisi Driver login + Amount.
6. Operator memeriksa nilai + tekan OK/Save di AIST secara manual. Bookmarklet TIDAK submit dan TIDAK menandai Lunas.
7. Setelah AIST mengembalikan sukses, kembali ke Finance → klik ✓ Konfirmasi AIST Berhasil (jalur manual eksisting) untuk menandai Lunas.

⚠️ Payload TTL: 10 menit. Kalau lebih lama, ulangi dari step 3.

3. Fallback manual

Kalau browser menolak clipboard read/write: pakai tombol 📋 Login dan 📋 Nominal di baris yang sama, lalu paste manual ke form AIST.

4. Perbedaan vs bookmarklet lama

Lama (V1 sheet queue): baca dari Google Sheet Pengisian Saldo, tandai isi = checkbox kolom G.
Lama (V2 sebelum sesi ini): bookmarklet fetch finance_saldo_raos_list dari GAS, mengirim rifim_auth.access_token cross-origin, dan memanggil finance_saldo_raos_mark_paid otomatis setelah fill.
V2 semi (2026-08-26): bookmarklet tidak memanggil GAS, tidak membaca rifim_auth, dan tidak menandai Lunas. Sumber pilihan = Finance UI. Handoff = clipboard MENALA_AIST_V2:<base64> dengan TTL 10 menit.

5. Troubleshooting

🔴 "Clipboard kosong / bukan payload MENALA_AIST_V2" → kembali ke Finance dan klik 🪄 Fill AIST dulu.
🔴 "Form AIST tidak terdeteksi" → buka form Balance replenishment dulu, tunggu Amount + Driver login muncul, baru klik bookmark.
🔴 "Payload kedaluwarsa" → payload >10 menit. Pilih ulang di Finance.
🔴 "Read-back Amount TIDAK cocok" → jangan tekan OK di AIST. Cek input custom / mask / mata uang, atau paste manual pakai Copy Nominal.
🔴 Browser tolak navigator.clipboard → pastikan tab AIST punya user gesture (klik bookmark), atau gunakan mode manual.
