AIST Fill v2 — Bookmarklet Install

Auto-fill Amount + Driver login di modal AIST Balance replenishment, langsung dari raos_saldo_requests Supabase (bukan sheet lama).

1. Drag tombol ini ke bookmark bar

🔴 AIST Fill v2

Tarik ke Bookmarks Bar Chrome/Edge/Brave. Kalau bookmark bar tidak muncul: tekan Ctrl+Shift+B.

2. Cara pakai

[Sekali] Login rifim-os.vercel.app/portal pakai email admin. Auth token disimpan di localStorage.
[Setiap sesi] Buka AIST → Documents → Add → Balance replenishment. Pilih Subdivision + Currency manual.
Klik bookmark "AIST Fill v2" → picker floating muncul di kanan atas.
Klik salah satu row driver → input Amount + Driver login di modal AIST otomatis terisi. Row auto-hilang dari picker + is_processed=true di Supabase.
Klik OK di modal AIST untuk kirim ke AIST.

3. Bedanya dari bookmarklet lama

Lama (spreadsheet Pengisian Saldo, sheet Jawaban Formulir 1):
• Baca dari sheet Google, filter row tanpa checkbox G
• Mark isi = centang checkbox G di sheet

Baru v2:
• Baca langsung dari Supabase raos_saldo_requests (via GAS Web App)
• Mark isi = PATCH is_processed=true di DB → auto-trigger notif ke staff PWA
• Filter status=approved (koord/admin sudah setujui)
• Auto-refresh 30 detik (pengajuan baru dari PWA RAOS langsung muncul)

4. Troubleshooting

🔴 "Belum login Rifim-OS" → buka portal, login dulu.
🔴 "Tidak nemu input Amount/Login" → pastikan modal AIST sudah terbuka + input visible.
🔴 Picker tidak muncul → cek console browser (F12). Kemungkinan AIST punya CSP block script. Coba akses AIST via HTTP (bukan HTTPS strict).
🔴 Row tidak refresh → klik tombol 🔄 di picker header, atau reload picker (klik bookmark lagi).
