Fill AIST Saldo - Bookmarklet Install (One-Click V2.1)

Bookmarklet field-filler untuk form Balance replenishment di AIST. Operator login ke RIFIM, buka AIST, klik bookmark, pilih antrian, lalu verifikasi manual.

1. Drag tombol ini ke bookmark bar

Fill AIST Saldo

Tarik ke Bookmarks Bar Chrome/Edge/Brave. Kalau bar tidak muncul: Ctrl+Shift+B.

2. Alur operator (one-click, non-Lunas)

1. Login ke RIFIM Finance seperti biasa (satu sesi browser).
2. Buka AIST → Document → Add → Balance replenishment. Pilih Subdivision + Currency manual.
3. Klik bookmark Fill AIST Saldo. Popup RIFIM muncul sebentar, lalu modal antrian muncul langsung di AIST.
4. Klik baris yang sesuai (verifikasi Cabang / Staff / Driver / Login / Saldo / Invoice).
5. Bookmarklet mengisi Driver login dan Amount dengan SALDO RAW, lalu membaca kembali. Jika tidak cocok → fail closed, JANGAN submit.
6. Operator memeriksa nilai + tekan OK/Save di AIST secara manual. Bookmarklet TIDAK submit dan TIDAK menandai Lunas.

3. Keamanan

Token 10 menit: RIFIM membuat token aist_queue_read scoped yang ditandatangani AIST_HANDOFF_SECRET dan dikirim ke AIST via postMessage origin-locked.
Tidak ada clipboard: normal flow tidak menyalin token. Tidak perlu klik Siapkan AIST Queue di Finance.
Queue: sumber kanonik Supabase raos_saldo_requests, sama dengan Finance → Isi Saldo (RAOS).
No auto-Lunas: bookmarklet tidak pernah memanggil GAS, tidak memutasi status, tidak menandai Lunas.

4. Troubleshooting

🔴 "Popup diblokir" → izinkan popup untuk https://aist-id.taxsee.com di browser, lalu ulangi.
🔴 "Sesi RIFIM tidak ditemukan" → login ke RIFIM Finance di tab mana saja di browser yang sama, lalu ulangi.
🔴 "Token AIST tidak valid, expired" → popup akan membuat token baru. Jika gagal, tutup popup dan klik bookmark lagi.
🔴 "Form AIST tidak terdeteksi" → buka form Balance replenishment dulu, tunggu Amount + Driver login muncul, baru klik bookmark.
🔴 "Read-back Amount TIDAK cocok" → jangan tekan OK di AIST. Cek input custom / mask / mata uang, atau paste manual.
